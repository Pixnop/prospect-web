---
title: Game versions
description: Install several Vintage Story versions side by side, no account needed.
---

A game version installs independently of any instance: it is the shared engine
(the game's own files), not a save profile. Several instances can point at the
same installed version without downloading anything twice.

## Two channels

- **stable**: normally numbered releases, `1.21.3` for example.
- **unstable**: release candidates, suffixed `-rc.N`, such as `1.22.0-rc.1`.
  They are listed separately and can be hidden.

## No account required

Listing and downloading game versions requires no vintagestory.at account: the
catalog and the files are public, served straight from the official
infrastructure. You can install Vintage Story before ever thinking about
logging in.

## Installed and available

The Versions screen separates what is already on your disk from what is left to
install, with each download's size stated plainly (`578.9 MB`, say) before
anything starts.

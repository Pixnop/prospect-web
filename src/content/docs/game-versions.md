---
title: Game versions
description: Install several Vintage Story versions side by side, no account needed.
---

A game version installs independently of any instance: it is the game's own
files, shared by every instance that points at it, not a save profile. Several
instances can use the same installed version without downloading anything
twice.

## Stable and test versions

- **stable**: normally numbered versions, `1.21.3` for example.
- **test versions**: candidates for the next stable, suffixed `-rc.N`, such as
  `1.22.0-rc.1`. They carry an `unstable` badge, are listed apart, and a toggle
  on the Versions screen shows or hides them.

## No account required

Listing and downloading game versions requires no vintagestory.at account: the
catalog and the files are public, served straight from the official
infrastructure. You can install Vintage Story before ever thinking about
signing in.

## Installed and available

The Versions screen separates what is already on your disk from what is left to
install, with each download's size stated plainly (`578.9 MB`, say) before
anything starts. An install only counts once it is checked: the game's files
must really be where they belong, or the version is not marked installed.
Uninstalling a version is one click on its row and frees the disk.

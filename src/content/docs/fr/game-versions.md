---
title: Les versions du jeu
description: Installe plusieurs versions de Vintage Story côte à côte, sans compte.
---

Une version du jeu s'installe indépendamment des instances : c'est le moteur
partagé (les fichiers du jeu lui-même), pas un profil de sauvegarde. Plusieurs
instances peuvent pointer vers la même version installée, sans rien retélécharger.

## Deux canaux

- **stable** : les versions numérotées normalement, par exemple `1.21.3`.
- **unstable** : les versions candidates, suffixées `-rc.N`, par exemple
  `1.22.0-rc.1`. Elles sont affichées à part et peuvent être masquées.

## Aucun compte requis

Lister et télécharger une version du jeu ne demande aucun compte
vintagestory.at : le catalogue et les fichiers sont publics, servis directement
par l'infrastructure officielle. Tu peux installer Vintage Story avant même
d'avoir pensé à te connecter.

## Installées et disponibles

L'écran Versions sépare ce qui est déjà sur ton disque de ce qui reste à
installer, avec la taille de chaque téléchargement affichée en clair (par exemple
`578.9 MB`) avant de lancer quoi que ce soit.

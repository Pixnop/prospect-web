---
title: Les versions du jeu
description: Installe plusieurs versions de Vintage Story côte à côte, sans compte.
---

Une version du jeu s'installe indépendamment des instances : ce sont les
fichiers du jeu lui-même, partagés par toutes les instances qui la choisissent,
pas un profil de sauvegarde. Plusieurs instances peuvent pointer vers la même
version installée, sans rien retélécharger.

## Versions stables et versions de test

- **stable** : les versions numérotées normalement, par exemple `1.21.3`.
- **versions de test** : les candidates à la prochaine stable, suffixées
  `-rc.N`, par exemple `1.22.0-rc.1`. Elles portent une pastille `unstable`,
  sont affichées à part, et un interrupteur de l'écran Versions les montre ou
  les masque.

## Aucun compte requis

Lister et télécharger une version du jeu ne demande aucun compte
vintagestory.at : le catalogue et les fichiers sont publics, servis directement
par l'infrastructure officielle. Tu peux installer Vintage Story avant même
d'avoir pensé à te connecter.

## Installées et disponibles

L'écran Versions sépare ce qui est déjà sur ton disque de ce qui reste à
installer, avec la taille de chaque téléchargement affichée en clair (par exemple
`578.9 MB`) avant de lancer quoi que ce soit. Une installation ne compte que
vérifiée : les fichiers du jeu doivent réellement être à leur place, sinon la
version n'est pas marquée installée. Désinstaller une version tient en un clic
sur sa ligne et libère le disque.
